# Weather & City Lookup Web App

## Overview

This project is my Module #3 submission for CSE 310 – Applied Programming.  
Module: **Language – JavaScript**

The app lets a user type a city name and see the current weather for that city using the OpenWeatherMap API. It demonstrates JavaScript fetch calls, DOM manipulation, basic error handling, and (optionally) city autosuggest using the GeoDB Cities API.

---

## Features

- User can type a city name and fetch current weather
- Weather data includes:
  - Temperature (°C)
  - Feels like (°C)
  - Humidity
  - Description
  - Weather icon
- Error message when city is not found or API fails
- Optional city autosuggest (GeoDB Cities API)
- Responsive layout with simple styling
- Code organized into HTML, CSS, and JavaScript files
- Function-level comments in `script.js`

---

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- OpenWeatherMap API
- (Optional) GeoDB Cities API via RapidAPI
